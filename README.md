# Ayantika Gangopadhyay — Research Portfolio

## Files
- `index.html` — portfolio content and structure
- `style.css` — dark theme, layout, hover states and responsive styling
- `script.js` — navigation and interactive behaviour
- `Ayantika_Gangopadhyay_CV.pdf` — downloadable academic CV

## Deploy / update
Upload all five files to the root of the `main` branch of the GitHub Pages repository and commit the changes.

The homepage CV buttons link to `Ayantika_Gangopadhyay_CV.pdf`.

## Content notes
Research experience, publications, projects, education and skills are based on the supplied Europa CV. Home and About sections retain the existing website content. Personal residential address and place of birth have deliberately not been published.
